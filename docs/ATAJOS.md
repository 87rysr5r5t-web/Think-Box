# Atajos de Think Box

La paleta muestra los atajos declarados en el registro de comandos. Los controles de edición que macOS proporciona conservan su funcionamiento nativo.

| Atajo | Acción | Origen |
| --- | --- | --- |
| ⌘N | Nuevo texto Markdown | Think Box existente |
| ⌘O | Abrir base de datos | Archivo |
| ⌘⌫ | Mover a la papelera | Datos |
| ⌘F | Buscar en la vista actual | Think Box existente |
| ⇧⌘I | Importar archivos | Think Box |
| ⇧⌘L | Mostrar u ocultar barra lateral | Think Box |
| ⇧⌘P | Paleta de comandos | Especificación, ST-13 |
| ⌘P | Ir a un documento o grupo | Especificación, ST-13 |
| ⌘, | Ajustes | macOS |
| ⌥⌘1 | Vista de página en el editor | Fase 2.B |
| ⌥⌘2 | Vista de página en la previsualización | Fase 2.B |
| ⌥⌘3 | Vista de página en ambos paneles | Fase 2.B |
| ⌥⌘0 | Desactivar ambas vistas de página | Fase 2.B |
| ⌘↩ | Insertar salto de página | Fase 2.B |
| ⌥⌘P | Imprimir texto paginado | Fase 2.B |
| ⌘+ / ⌘− / ⌘0 | Acercar, alejar o ajustar a la página | Fase 2.B |

| ⌥⇧⌘S | Guardar espacio de trabajo | Ir → Espacios de trabajo |
| ⌥⌘O | Mostrar u ocultar esquema | Visualización |
