# Atajos de Think Box

La paleta muestra los atajos declarados en el registro de comandos. Los controles de edición que macOS proporciona conservan su funcionamiento nativo.

| Atajo | Acción | Origen |
| --- | --- | --- |
| ⌘N | Nuevo texto | Think Box existente |
| ⌘F | Buscar en la vista actual | Think Box existente |
| ⇧⌘I | Importar archivos | Propuesto. Verificar con DEVONthink 4 |
| ⇧⌘L | Mostrar u ocultar barra lateral | Propuesto. Verificar con DEVONthink 4 |
| ⇧⌘P | Paleta de comandos | Especificación, ST-13 |
| ⌘P | Ir a un documento o proyecto | Especificación, ST-13. Verificar al añadir impresión global |
| ⌘, | Ajustes | macOS |
